# medChat

A medical chat application for connecting patients with care.

## About

medChat is a full stack app that lets patients and healthcare providers communicate, with a React client and a Node.js server.

## Features

- Patient and provider chat
- Full stack React and Node architecture
- Clean and simple interface

## Tech Stack

- React
- Node.js
- Express
- MongoDB

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
